# Mini Project: React Styling - RS MedikaCare

Proyek ini merupakan implementasi komponen React, styling Tailwind CSS, dan komunikasi Parent-Child menggunakan Props untuk halaman utama Rumah Sakit MedikaCare.

## Cara Menjalankan Proyek

1. Ekstrak file ZIP ini.
2. Buka folder proyek di terminal / VS Code.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Jalankan server development:
   ```bash
   npm run dev
   ```
5. Buka URL localhost yang muncul di browser.
